# Examples Kernel

`Examples/kernel/` contains the maintained, regression-relevant `.lp` set.
Each file is kept small and tied to one property.

## Current Kernel Set

- `asp_convergence.lp`: convergence target for `--3nd-star` vs plain clingo.
- `bnm_totality.lp`: `--bnm`/`--3nd` totality-oracle parity checks.
- `bnm_children_flip.lp`: shallow-depth non-monotonic behavior under `--bnm`.
- `bnm_children_open.lp`: children puzzle with the open question (`#external blonde(martha)`) declared, so the k=0 committal "No" flips to the derived cautious "Yes" at k=1 via the case split on Martha's hair.
- `flip_tf.lp`: direct T→F cautious polarity flip at k=0→1 (presumption→derivation handover on a bivalence gap).
- `flip_fut.lp`: three-status trajectory F→UNDEC→T (width-3 classical entailment of an atom outside all stable models).
- `flip_width4.lp`: T→UNDEC→T with a suspension interval ending at k=4 (refutation width; generated by `scripts/gen_flip_gadget.py 4`).
- `3nd_formal_resolution.lp`: small formal-resolution fixture used by `--3nd` cautious checks.
- `enum_modes.lp`: output-mode differences (`all|brave|cautious`).
- `unsat.lp`: unsatisfiable baseline.
- `sudoku_depth_hump.lp`: runtime/depth hump benchmark.

## Verification Commands

```sh
./.venv/bin/python scripts/regress_semantics.py
./.venv/bin/python klingo --3nd-star -k 2 -n 0 --mode all Examples/kernel/enum_modes.lp
./.venv/bin/python klingo --bnm -k 1 -n 1 --mode all Examples/kernel/bnm_children_flip.lp
```

## Curation Rules

- Keep `Examples/kernel/` stable and regression-safe.
- Move exploratory/temporary encodings out of `Examples/kernel/`.
- Put scratch experiments under `Examples/scratch/` (gitignored by default) if needed.
